# Work workflow rules

The whole `Work/` tree is employer-confidential. Keep every operation local.

## Daily Notes

- Path: `Work/Daily Notes/<N. Month YYYY>/YYYY-MM-DD.md`.
- Existing numbered/nested checkboxes remain untouched.
- New terminal-created tasks go under an appended `## Command Center` section.
- Completion toggles only the matched checkbox; it never renumbers or rewrites
  surrounding content.
- The briefing may show checkbox titles, dates, and paths. It does not summarize
  surrounding prose unless explicitly requested.

## Brag doc

- Source: latest file under `Work/Brag doc/`.
- Before appending, show the exact proposed bullet and target path.
- Append only after explicit confirmation.
- Never auto-generate claims or metrics. Drafts must be grounded in an existing
  Work source supplied or selected by the user.

## 1-1

- Path: `Work/1-1/YYYY-MM-DD.md`.
- Treat contents as HR-sensitive.
- Default queries show only available dates and the latest file.
- Read a body only when the user names or selects the meeting.
- Before appending, confirm exact text, date, and target path.

## Connects

- Source: latest file under `Work/Connects/`.
- Drafting may use local Daily Notes and Brag sources only.
- Show the draft and target path before appending.

## Other sources

- `Work/Quarterly Tasks.md`: append under `## Command Center`; preserve existing
  prose and headings.
- `Work/Queries.md`: local snippet/reference library; append only on request.
- `Work/Generic Notes.md`: append-only scratch/reference notes.
- `Work/Updates EngMs*.md`: index/search; no special mutation.
- `Work/Drawings/*.md`: title/index only; never parse or edit Excalidraw data.
